# 자유조사

## 제2차 세계대전 전술

1939~1945년에 실전에서 쓰인 전술 22개를 육상·해상·공중으로 나눴다. 소부대 교전, 편대 전술, 작전급 기동을 함께 다루며, 각 항목에 비교할 때 필요한 제대를 표시했다. 전술명이 당시 자료에 직접 등장하지 않는 경우에는 사례의 작동 원리를 설명하는 이름으로 사용했다.

### 인물 근거 읽는 법

- **채택·주도**는 인물이 해당 방식을 고안하거나 명시적으로 지시하고 채택을 주도했다는 기록이 있는 경우다. 이 경우에도 근거가 뒷받침하는 기간과 임무 안에서만 선호를 해석한다.
- **실전 운용**은 작전을 지휘하거나 직접 사용한 사실이 확인되는 경우다. 그 인물이 평소에 이 전술을 선호했는지는 별도로 확인해야 한다.
- **계획·체계**는 작전 설계나 교리·지휘 체계의 수립에 관여한 인물이다. 계획자, 현장 지휘관, 직접 사용자가 다르면 따로 표시한다.

상성에서 말하는 우위는 해당 교전에서 목표를 달성할 가능성을 뜻한다. 예를 들어 항로 방어라면 선단 통과가, 공수작전이라면 거점 확보와 지상군 연결이 우선이다. 서로 다른 제대의 전술은 같은 임무에서 부딪히는 지점만 비교했다.
