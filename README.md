# WW2 Archive

제2차 세계대전 백과사전 프로젝트의 원본 저장소입니다.

## 기본 구성
- `docs/` — 공개할 Markdown 백과사전 문서
- `zensical.toml` — 정적 사이트 빌드 설정
- `.github/workflows/pages.yml` — GitHub Pages 자동 배포

## 편집 원칙
역사적 사실과 해석을 구분하고, 검증 가능한 근거와 출처를 기록합니다. 처음에는 구조만 구성하며, 백과사전의 상세 분류와 내용은 추후 확정합니다.

## 배포
GitHub 저장소의 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하면 자동 배포 워크플로를 사용할 수 있습니다.
