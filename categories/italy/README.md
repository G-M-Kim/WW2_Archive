# 이탈리아 — WW2 카테고리 조사

국가 코드 `IT`. 이 국가의 19개 항목을 순서대로 첫 조사한다. 아래 원고 파일은 해당 실행에서 실제 자료와 함께 생성한다. 1번은 L3/33·M11/39·M13/40의 제원과 북아프리카 포획 기록을 부분 조사했다. 2번은 AB41·세모벤테 75/18·Fiat 665 NM의 제원과 전시 자료를 부분 조사했다. 3번은 리토리오 전함·시레 잠수함·아퀼라 미완성 항모의 제원과 이력을 부분 조사했다. 4번은 C.202 전투기·S.79 폭격기와 뇌격기·S.82 수송기의 제원과 전시 기록을 부분 조사했다. 5번은 M91 소총·브레다 Mod.30 경기관총·M33 철모·T.35 방독면의 전시 자료를 부분 조사했다. 6번은 구포 함정 레이더·하겔린 C38m 해군 암호기·FIVRE M-213 송신부의 자료를 부분 조사했다. 7번은 메세·베르가미니·부스칼리아의 전투 참여와 지휘 경력을 부분 조사했다. 8번은 무솔리니·비토리오 에마누엘레 3세·바돌리오·치아노의 전시 정치 역할을 부분 조사했다. 9번은 티베리오·카라라의 전파 연구와 카스톨디·가브리엘리의 전시 항공기 설계를 부분 조사했다. 10번은 무솔리니 참전·밀라노 연설의 당대 필름과 바돌리오 휴전 방송 자료를 부분 조사했다. 11번은 피아트·안살도·마녜티 마렐리·FIVRE의 전시 생산 및 제노바 노동 탄압을 부분 조사했다. 12번은 본토의 인구총조사·전시 추계와 리비아·동아프리카·에게해 인구를 부분 조사했다. 13번은 카시빌레·피우메·폴라·로도스·트리폴리의 전시 표기와 현대 대응명을 부분 조사했다. 14번은 왕국·식민지·점령지의 지위와 1943년 이후 군정·평화조약을 부분 조사했다. 15번은 알바니아 원유·크롬, 이탈리아 본토 강철·알루미늄, 합성고무 시설 및 텅스텐 수입 자료를 부분 조사했다. 16번은 미라피오리와 테르니 제철소, 코르닐리아노 신설 제철소의 개전 시점 규모·가동 자료를 부분 조사했다. 17번은 같은 세 사업장의 종전 피해·반출·재가동과 실제 자료 시점을 부분 조사했다. 현재 17/19 항목을 방문했다.
