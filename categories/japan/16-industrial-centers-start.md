# 일본 16 · 개전 시점 주요 공업단지와 규모

작업 ID `CAT-JP-16`. 첫 조사 상태는 `partial`이다. **1939-09-01**을 공통 개전 기준일로 삼았다. 1937년부터 이어진 중일전쟁의 산업 동원, **1941-12-08** 일본의 대미·대영 선전 조서, **1945-09-02** 일본의 항복문서 조인은 각기 다른 시점이다. 이 원고에서는 공장별 1938–1939년 관측치를 기준일과 구분했다. ## 시설의 범위와 1939년 9월 1일 상태

## 공통 척도와 후속 검증

[공통 평가 기준](../INFRASTRUCTURE_RATING.md)의 네 차원은 면적·집적, 업종별 설비 생산능력, 작업 수용 규모, 전력·철도·항만 처리설비 순이다. 고로 개수는 설치의 일부, 생산·고용은 운영의 지표다. 확인된 수치로는 동일 기간의 물리적 면적·설비 정격·수용 규모·처리량과 등급 경계가 성립하지 않는다. 세 사업장의 차원 등급과 점수·범위는 모두 `null`이다. 1945-09-02 비교에서 같은 GEO ID 및 사업장 범위를 사용하고, 원자료가 더 넓거나 좁으면 범위 차이를 표시한다.

- `CAT-JP-RQ-0051` · 야하타의 구역별 필지·설비·동시 가동, 인력 집계와 도요제철 포함 여부.
- `CAT-JP-RQ-0052` · 히로하타의 공사 단계별 설치 면적·생산설비·전용 설비 정격, 개전 당시와 종전 시 같은 사업장 비교.
- `CAT-JP-RQ-0053` · 겸이포의 연도별 설비·생산 원장, 항만 처리량과 노동 실태, 본토·식민지의 추가 사례.
