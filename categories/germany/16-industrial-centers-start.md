# 독일 — 개전 시점 주요 공업단지와 규모

작업 ID `CAT-DE-16` · 첫 검사 `partial` · 기준일 **1939-09-01**

독일의 폴란드 침공일인 1939년 9월 1일을 기준으로 루르의 석탄·제철 집적지와 라우타베르크의 알루미늄 생산시설을 조사했다. 루르는 당시 전국 제강 설비에서 차지한 비중, 라우타베르크는 같은 제련 업종의 독일 공장별 설비 추정표를 근거로 선정했다. 독일의 군사 항복 문서는 1945년 5월, 연합국의 최고권한 인수 선언은 6월 5일에 해당한다. 종전 편의 공통 비교일은 1945년 9월 2일이며, 이 편은 개전 상태만 다룬다. [CAT-DE-SRC-0100, 침공 문단](https://encyclopedia.ushmm.org/content/en/article/german-administration-of-poland) · [CAT-DE-SRC-0103, 인쇄 6–13쪽](https://tile.loc.gov/storage-services/service/ll/llmlp/61035888_Volume-I/61035888_Volume-I.pdf) · [CAT-DE-SRC-0109, 10–11쪽](https://www.ibiblio.org/hyperwar/AAF/USSBS/ETO-Summary#page10) · [CAT-DE-SRC-0112, 9쪽 표 2](https://tile.loc.gov/storage-services/public/gdcmassbookdig/eliminationofnaz00unit/eliminationofnaz00unit.pdf#page=143)

전쟁 말 지역별 사건으로는 1945년 4월 18일 루르 포위망 내 독일군 저항 종결과 4월 20일 소련군의 라우타 점령이 확인된다. 각 공장의 인수와 가동 상태는 별도 확인이 필요하다. [CAT-DE-SRC-0123, 105쪽](https://history.army.mil/portals/143/Images/Publications/catalog/70-58.pdf) · [CAT-DE-SRC-0120, 전쟁 말 문단](https://www.brandenburgikon.net/index.php/de/unternehmen-bis-1945/niederlausitz/lauta)
