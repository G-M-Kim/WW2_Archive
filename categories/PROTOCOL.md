# 국가별 154개 조사 운영 프로토콜

1. 최신 브랜치 HEAD의 `categories/RESEARCH_STATE.json`에서 현재 job_id를 읽고, `categories/QUEUE.json`에서 해당 원고 경로를 확인한다. 최초 정합성 검사를 제외하고 전체 154개 문서를 매번 열지 않는다. 조사 순서는 국가 DE→FR→GB→US→JP→IT→SU, 각국 01~22번이다.
2. 현재 원고와 해당 국가 SOURCES/QUESTIONS의 필요한 부분만 읽는다. 실제 원문을 대조한 내용과 출처 ID·페이지를 핵심 주장에 연결하고, 검증된 기존 내용은 이유 없이 재검색하지 않는다.
3. 연구 증분은 **기존 국가별 NN-*.md 원본**에 직접 저장한다. 리뷰용 상태 파일이나 보고서만 갱신하는 것은 조사 진전이 아니다. 출처 등록부와 미해결 과제, 현재 커서를 최소한으로 갱신한다.
4. 각 하위 유형의 필수 정보가 검증되면 완료, 조사 대상 유형들을 점검했지만 미해결 근거가 있으면 REVIEWED_WITH_GAPS로 둔다. 완료된 문서 목록과 미해결 문서는 별도 집계하며 REVIEWED_WITH_GAPS는 COMPLETE가 아니다. 접근 불가 원자료는 재개 조건을 남기고 다른 항목으로 전환한다.
5. 파일 변경과 진행 기록은 가능하면 한 커밋으로 저장한다. 원격 HEAD 경합과 중복 저장을 검사하고, 저장 실패 시 커서를 전진시키지 않는다. 본 브랜치에 main/다른 예약을 무단 병합하지 않는다.
6. `python categories/tools/validate.py`로 ID, 경로, JSON, 출처 참조 등을 구조 검사한다. 이 PASS는 역사적 사실 검증이 아니다. 채팅에는 실제 조사 결과·문서·출처·커밋·다음 위치를 3~5줄만 보고한다.

특수 규칙: 장비의 형식/양산/시제품/배치와 제원 조건, 인구·자원·지명의 기준 연도·경계·단위, 식민지/점령지, 영상의 실제/편집/음성 여부를 구별한다. 16~19 시설 점수는 INFRASTRUCTURE_RATING.md에 따르며 근거 없는 점수는 null이다. 20~22 교리는 교범·이론·실제 작전과 반례를 대조한다.
