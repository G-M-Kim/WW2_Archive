# 첫 순회 실행 증빙

이 디렉터리의 133개 JSON은 7개국의 01~19번 첫 순회 결과를 보존하는 개별 실행 기록이다. 기존 원고의 상대 링크를 유지하기 위해 이 경로를 유지한다.

- 각 파일은 `CAT-국가코드-카테고리번호.json` 형식이다.
- 이력은 조사 당시의 확인 범위와 제약을 보여주는 증빙이다. 새 154개 카테고리 심화 조사의 현재 상태나 완료 근거로 사용하지 않는다.
- 현재 진행 상태는 `categories/RESEARCH_STATE.json`, 전체 원고 목록은 `categories/QUEUE.json`에서 확인한다.
