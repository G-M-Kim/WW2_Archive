# 프랑스 — WW2 카테고리 조사

국가 코드 `FR`. 이 국가의 19개 항목을 순서대로 첫 조사한다. 아래 원고 파일은 해당 실행에서 실제 자료와 함께 생성한다. 01번은 B1 bis·SOMUA S 35·Renault R35의 무장·기동과 운용 근거를 부분 조사했다. 02번은 판아르 178·르노 UE·로렌 37 L의 무장과 기동 조건을 부분 조사했다. 03번은 전함 장 바르와 기뢰부설 잠수함 뤼비의 전시 무장·운용을 부분 조사했다. 04번은 D.520 전투기와 MB.220 수송기의 제원·전시 운용을 부분 조사했다. 05번은 MAS 36 소총, FM 24/29 경기관총과 나르비크의 프랑스제 군장을 부분 조사했다. 06번은 다비드 전자기 경보망, 포르크로 펄스 레이더와 레지스탕스의 B2 무전기를 부분 조사했다. 현재 6/19 항목을 방문했다.
