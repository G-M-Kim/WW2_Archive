# 프랑스 — WW2 카테고리 조사

국가 코드 `FR`. 이 국가의 19개 항목을 순서대로 첫 조사한다. 아래 원고 파일은 해당 실행에서 실제 자료와 함께 생성한다. 01번은 B1 bis·SOMUA S 35·Renault R35의 무장·기동과 운용 근거를 부분 조사했다. 02번은 판아르 178·르노 UE·로렌 37 L의 무장과 기동 조건을 부분 조사했다. 03번은 전함 장 바르와 기뢰부설 잠수함 뤼비의 전시 무장·운용을 부분 조사했다. 04번은 D.520 전투기와 MB.220 수송기의 제원·전시 운용을 부분 조사했다. 05번은 MAS 36 소총, FM 24/29 경기관총과 나르비크의 프랑스제 군장을 부분 조사했다. 06번은 다비드 전자기 경보망, 포르크로 펄스 레이더와 레지스탕스의 B2 무전기를 부분 조사했다. 07번은 르클레르·롤탕기·무쇼트의 전시 지휘와 전투 역할을 부분 조사했다. 08번은 페탱·라발·드골의 권한과 유대인 박해 정책, 해방기의 법질서 회복을 부분 조사했다. 09번은 프랑스 핵분열 연구팀과 피에르 다비드의 방공 탐지 연구를 부분 조사했다. 10번은 드골의 런던 방송 음성·바외 무성 촬영본·파리 해방 연설 영화의 보존 정보와 접근 한계를 부분 조사했다. 11번은 르노의 트럭 생산·노동 동원과 LMT·CGCT의 통신기기 계약·제조를 부분 조사했다. 12번은 본토 총조사·전시 추계와 알제리·튀니지의 별도 인구 자료를 부분 조사했다. 13번은 스트라스부르 개명과 사이공·쩌런의 전시 지명을 부분 조사했다. 14번은 본토 점령·해방, 적도아프리카·카메룬 및 인도차이나의 영토와 통치 변화를 부분 조사했다. 15번은 프랑스 본토와 인도차이나·누벨칼레도니의 전시 자원 여섯 종을 부분 조사했다. 현재 15/19 항목을 방문했다.
