## 원고와 빌드

역사자료의 정본은 저장소 루트의 `chronology/`, `categories/`, `research/`에 있습니다. 이 `docs/` 디렉터리는 공개 위키의 진입 페이지와 편집 안내, 출처 안내, 인터랙티브 타임라인 자산을 보유합니다.

월별 연표 페이지와 7개국 카테고리 페이지는 빌드할 때 정본 Markdown에서 생성됩니다. 따라서 `docs/chronology/`와 `docs/categories/`는 추적하지 않는 빌드 산출물이며 직접 편집하지 않습니다. 타임라인의 `index.html`, CSS, JS 및 `photos/`는 실제 배포 자산이므로 보존합니다.
