# 카살라–케루–아고르다트 공세 검토 초안
관련 EVT-3249·3255·3261·3268. 바렌투·케렌의 2월 전투로 연결되며 이번 범위에서 전역 종결을 선언하지 않는다.

## 배경·구상·지휘
Wavell의 총괄 아래 수단 방면 Platt가 진격했다. 제4인도사단장은 Beresford-Peirse, 제5인도사단장은 Heath, 기동 Gazelle Force는 Messervy가 지휘했다. 기존 이탈리아 국경 진지 공격 계획은 적의 선행 철수 뒤 추격으로 바뀌었다. [SRC-1757](chronology-sources-v1.md) pp3528~3535·[SRC-1758](chronology-sources-v1.md) pp397~400.

카살라에서 제4사단은 북측 케루 경로, 제5사단은 테세네이–아이코타–바렌투 경로로 나아갔다. 산악 통로·급수·도로 파괴·차량 부족이 전개를 제한했다. [SRC-1755](chronology-sources-v1.md) pp40~49.

전차 지원에는4RTR의B중대, 기동부대에는 Skinner’s Horse와 Sudan Defence Force 부대가 포함됐다. [SRC-1756](chronology-sources-v1.md)·[SRC-1758](chronology-sources-v1.md).
부대 약칭의 분수는 대대/연대 표시다. 인도군을 영국인 병사로 바꾸어 표기하지 않는다. 명부에 있는 제7여단과 다른 지역의 제9여단을 카살라 주공에 모두 더하지 않는다.

## 실제 인원·적정
| 수치 | 기간·지역·성격 |
|---|---|
| 제4·5사단 및 별도부대의19일 현원 | **미확인**; 편제 명부에 인원 총계 없음 |
| 수단28,000명 | SRC-1758 p397의 **1940년10월 말** 총원;1월 공세 인원으로 사용 금지 |
| 카살라 일대 이탈리아13,500명 | 같은 전사의 앞선 배치 설명상 영국 추정;1/19 확정 현원 아님 |
| 남부 케냐 방면 | 제1남아공·제11/12아프리카사단이라는 별도 전구 집단; 수단군에 합산하지 않음 |

케냐 편제는 SRC-1757 서두§2와별첨에 확인된다. 사단별 실제 인원은 RQ-1024로 남겼다. 전쟁 시작 당시 수단9,000명이나 케냐의 다른 달 총원을 지금의 공격군으로 쓰지 않는다.

## 전투 단계와 날짜 차이
| 날짜 | 기록 |
|---|---|
| 19일 | 카살라 진격 시 이미 적 철수; 확보 뒤 추격 |
| 22~24일 | 이탈리아 케루 철수·영연방군 확보와 협곡 통과; 자료별 시각 차이 |
| 25일 | 아고르다트 전방 접촉 |
| 26일 | 제29여단 고그니 공격·반격 |
| 31일 | 제5여단과 보병전차의 방어선 돌파·퇴로 차단 |
| 2월1일 | 인도 전사는07:00 아고르다트 무저항 점령으로 기록 |
| 2월2일 | 바렌투 점령으로 기록;1월로 소급 금지 |

위 단계는 SRC-1755 pp42~49. Platt 보고는 케루 통과를23일15:00으로 기술하고 인도 전사는 Gazelle Force의 협곡 통과를24일05:30으로 구분한다. 부대·지점 차이인지 일자 오류인지 RQ-1025로 검증한다. **31일 방어선 붕괴와 도시 점령은 별개**로 보존한다.

아고르다트 수비대는 인도 전사에서 식민여단2·12·42, 흑셔츠3대대, 포병·전차·Bande·독일중대 등으로 추정한다. 이것을 완편 사단 수나 이탈리아인 인원으로 환산하지 않는다. [SRC-1755](chronology-sources-v1.md).
당일 전투의 이탈리아·영연방 손실과 포로 총수는 미확인이다. 이후 케렌의 병력·전과를 이 단계로 소급하지 않는다.
