# 역사 백과사전 후속 조사 백로그 — 연구과제 영구 추적

> 이 파일은 **미완료 과제를 잊지 않기 위한 단일 추적장부**이다. 임시 메모가 아니며, 새로운 월간 조사마다 발견되는 한계·누락·잘못된 사료 링크를 RQ ID가 있는 행으로 추가해야 한다. **기존 RQ ID는 재사용하지 않는다.** 백과사전 검증 초안 브랜치 `draft/chronology-index-v1`에서 관리하며 현재 `main`과 공개 `docs/`에는 게시하지 않는다.

## 과제 상태 변경 규칙

- `open`: 미착수 또는 사료 확보 전. `in_progress`: 관련 조사가 문헌 검증과 함께 시작됨. `blocked`: 필요 원문 접근 불가·상충하는 원전 미해결. `done`: **최소 완료 조건을 증빙하는 실제 GitHub 문서와 출처 ID를 기록한 경우에만**.
- `done`으로 옮길 때는 해당 과제 행에 **완료일, 관련 EVT/SRC, 증거가 들어간 감사 보고서 파일 링크**를 함께 기록한다. 과거 의견만으로 완료하지 않는다.
- 월별 연구에서 미확인 사항을 발견하면 **답을 추측하지 말고 새로운 RQ 추가**. 동일한 과제가 이미 있으면 기존 RQ에 관련 사건을 덧붙인다.
- 매 조사 턴의 시작에는 이 파일을 먼저 읽고, 해당 조사 턴의 끝에는 상태를 갱신한다. 사용자가 '이어서 진행'만 요청하더라도 따를 작업 프로세스이다. 자동으로 백그라운드 연구가 진행되지는 않는다.
- 과제 마감은 '세계대전의 사건을 전부 발견했다'가 아니라 **명시된 범위의 출처·누락·쟁점 조사를 해당 기준에 맞춰 수행한 것**을 의미한다. 신규 사료 발견 시 재오픈 가능하다.
