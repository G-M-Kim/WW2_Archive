## 발견한 실제 오류

- GitHub HEAD `93012b336dd6d799dd77613efdf45518d2f544d7`에서 `WORK_STATE.md`의 FORWARD_CURSOR가 `1941-06-04`로 고정됨. 이미 1941년 6월 4~10일의 중국·중동·외교·미국 해운/수출 통제 등 선별 자료를 여러 실행에서 등록했으나, **미확인 지역과 원자료를 전부 마칠 때까지 커서를 유지하는 잘못된 완결 조건**으로 같은 범위가 반복됨.
- 기존 작업의 미해결 사항은 `research-backlog.md`에 RQ로 존재하고, 과거 자료 전체의 전수 확인은 현실적으로 개별 조사 실행의 성공 조건이 아님.
- 기존 자동화 프롬프트에도 1941-05-28과 과거 통계가 고정 예시로 들어가 있어 오래된 진행 지점을 다시 선택할 위험이 있었음. 시간별 자동화 지시문을 실제 GitHub 정본 우선·forward/backfill 분리로 갱신함.
- [이전 실패한 GitHub Actions 실행](https://github.com/G-M-Kim/WW2_Archive/actions/runs/42376972535)의 `validate_index.py` 실패는 `chronology-1939-1941.md`의 **1941-06-10 이후에 1941-06-04 및 1941-06-06 사건이 배치된 날짜 역순 오류**로 확인됨. 기존 사건 ID/내용을 바꾸지 않고 1941년 행들을 날짜 순으로 정렬하여 정본·미러를 동일하게 반영함.
