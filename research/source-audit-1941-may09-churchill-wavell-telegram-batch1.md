# 1941-05-09 처칠→웨이벌 이라크 공세 지시 사료감사 (batch 1)

- 감사일: 2026-11-06. 조사구간: 1941-05-09 (이라크·영국 전시지휘); **1941-05-04~09 세계 전역 조사 미완료**.
- 신규: EVT-3474 / SRC-1913 / RQ-1135. 원래 EVT/SRC/RQ ID 불변, 기존 5/9 지휘권 이양 EVT-3465 및 시리아 항공전문 EVT-3468과 별개.
- **확인한 자료:** Imperial War Museums (IWM), *Churchill and the Middle East* 전시 대형활자 안내서, 2024-07 공개 PDF, 표지물 설명 “RIGHT TABLE TOP 49”, PDF 검색 텍스트의 해당 전시물 설명. [IWM 전시 안내 PDF](https://www.iwm.org.uk/sites/default/files/files/2024-07/churchill_and_the_middle_east_large_print_guide.pdf).
- **원사료 소장 식별자:** Churchill Archives Centre, **CHAR 20/38/89**, Winston Churchill → General Sir Archibald Wavell, **1941-05-09** telegram. IWM 안내문에 기재된 식별자이며 원전보의 문구·서명·원문 페이지는 **직접 열람하지 않음**. 안내 PDF의 실제 인쇄 페이지 번호는 확인하지 못했으므로 인용하지 않음.
- **검증 가능한 최소 사실:** IWM의 소장품 설명은 5/9 처칠이 웨이벌에게 팔레스타인 방면에서 이라크 쿠데타 지지세력에 대한 적극적 공세를 지시하고 시리아에서 독일의 개입 위험을 강조했다고 설명한다. **명령 발신**은 확인되지만 실제 병력 이동, 공격 개시, 각 부대의 명령 수령일, 시리아 독일군 개입의 현실화는 이 자료만으로 확인되지 않는다.
- **사료 계층:** 1차 원전보의 소장번호를 확인한 **박물관의 2차 전시 해설 직접 열람**. 원전보를 직접 확인했다고 표시하지 않음. 다른 1차 지휘관 보고(SRC-1895)는 이라크 작전의 별개 지휘권 전환을 기술하지만 이번 전보 문구에 대한 독립 교차검증으로 간주하지 않음.
- **작전 규모:** 사단·여단·대대별 실제 투입, 보유전차·가동수·항공기, 명목 편제 대비 실인원, 영·이라크측 손실은 **미확인**. 표준 정원으로 역산 금지.
- **한계·권리:** 전시 캡션은 원문 전문이 아니며 처칠의 판단·전쟁지도 해설이 섞여 있다. 영국 지휘문서·웨이벌 수신문·현장 작전일지·이라크측 기록으로 교차검증 필요(RQ-1135). IWM PDF의 Crown/Churchill Archives Centre 표기를 따르며 전보 이미지·전시물 원문을 복제하지 않고 자체 한국어 요약만 기록.
- **중복 감사:** 1941-05-09 기존 EVT-3465(남부 이라크 작전통제권 인수) 및 EVT-3468(레이히의 시리아 항공기 전언)과 행위자·문서·명령 단계가 달라 독립 사건. 기존 ID 재번호 없음.
- **병합 게이트:** 연구 색인 부분검증만 수행. PR #1에는 docs/ 파일 5개가 포함되므로 main 병합은 출판영향 분리 검토 전 보류. CI는 신규 HEAD 검사 후 별도 확인.
