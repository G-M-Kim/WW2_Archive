# 1941-05-12 신규 날짜 조사 — 부분 색인

신규 **3 EVT / 3 SRC / 3 RQ**. 전 세계 전수조사 아님. 미일 외교·오세아니아 통상·중국 민간인 공습의 1차 외교문서 선별 검증.

- EVT-3480 / SRC-1920: 5월12일 노무라의 미일 비밀 양해각서 초안. FRUS Japan 1931–1941 vol.II doc.248 pp.420–423. 일본측 제안서이지 양국 합의·조약 아님. RQ-1141.
- EVT-3481 / SRC-1921: 5월12일 애치슨·멘지스·케이시 통상협력 회담. FRUS 1941 vol.III doc.80 p.115. 미국측 메모로 실제 협정·호주측 원기록 미확인. RQ-1142.
- EVT-3482 / SRC-1922: 5월17일 그루 항의 서한이 5월12일 쿤밍 공습과 미국 영사관·주택 피해를 기록. FRUS Japan 1931–1941 vol.I doc.528. 중국·일본 독립 원전 미대조. RQ-1143.

직접 확인한 미국 국무부 정부편집 원문: https://history.state.gov/historicaldocuments/frus1931-41v02/d248 ; https://history.state.gov/historicaldocuments/frus1941v03/d80 ; https://history.state.gov/historicaldocuments/frus1931-41v01/d528 (열람 2026-11-06). 원문 전문/이미지 복제 없음, 자체 한국어 요약. 미국측 기록의 관점·후대 편집 한계 및 원전 재배포권 미확인.

5월12일 소련의 라시드 알리 승인, 시리아 항공기 이동, 함부르크 공습 등 후보는 발생일·원전 확인 전 독립 EVT 보류. 유럽·아프리카·대서양·이라크·민간인 피해 후속 보강 필요. 5/4~9 BACKFILL_QUEUE 유지. **FORWARD_CURSOR 1941-05-13**. main/docs/Pages 불변.
