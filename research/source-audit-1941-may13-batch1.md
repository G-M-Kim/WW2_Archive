# 1941-05-13 신규 날짜 조사 — 부분 색인

신규 **3 EVT / 3 SRC / 3 RQ**. 세계 전역 전수조사 완료 아님. 미국 국무부 편집 1차 외교문서의 원문 웹 전사를 직접 확인함.

- EVT-3483 / SRC-1923 / RQ-1144: 중국 재정고문 Arthur N. Young의 5/13 비망록에서 전시 인플레이션을 평가하고 미영 공동 경제사절단을 제안. 작성/전달일 각주(5/13경) 구분. 중국측 독립 통계와 실제 사절단 파견 미검증.
- EVT-3484 / SRC-1924 / RQ-1145: 5/13 Leahy의 비시발 전문에서 독일 항공기의 시리아 경유와 프랑스군 군수품 이동에 관한 비밀 제보 보고. 보고 사실만 확인, 제보의 항공기 14대·수송량·지휘권자는 독립 원전 미확인. 5/12 Engert 및 5/13 Winant 전문과 추가 대조 필요.
- EVT-3485 / SRC-1925 / RQ-1146: 5/13 소련 대사 Umansky가 미국의 징발물자 관련 5/5 통보 수령을 확인하고 배상청구권을 유보한 서한. 실제 배상청구·지급 미확인.

원문: https://history.state.gov/historicaldocuments/frus1941v05/d679 ; https://history.state.gov/historicaldocuments/frus1941v03/d737 ; https://history.state.gov/historicaldocuments/frus1941v01/d709 (열람 2026-11-07). 미국 국무부 후대 편집 전사이며 중국·독일·비시·소련 원기록과 독립 대조 미완료. 원문·이미지 전문 재배포하지 않고 한국어 자체 요약만 작성. 이용권한 별도 확인 필요.

유럽 전선·북아프리카·대서양 해난·동아시아 교전·민간인 피해는 이번 배치에서 충분히 조사하지 못함. 5/4~9 BACKFILL_QUEUE 유지. **FORWARD_CURSOR 1941-05-14**. main/docs/Pages 불변.
