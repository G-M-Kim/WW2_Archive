## 디렉터리 원칙

- `source-audits/YYYY/`: 사료·날짜·수치 검토 보고서. 기존 원본 경로와 파일을 유지한다.
- `event-drafts/YYYY/`: 사건별 상세 조사 초안. 정본 연표를 대체하지 않는다.
- `coverage/chronology/`: 특정 날짜 구간의 조사 범위·세부 재개 자료.
- `archive/chronology/`: 이전 연도 범위별 연표 스냅샷.
- `archive/operations/`: 과거 작업 상태와 복구 기록. 현재 커서로 사용하지 않는다.

**정본 원칙:** 신규·보강 사건은 `chronology/YYYY-MM.md`, 근거는 `chronology-sources-v1.md`, 미해결 사항은 `research-backlog.md`에 반영한다. 감사·초안·범위 검토 파일만 수정한 것은 정본 조사 완료가 아니다.
