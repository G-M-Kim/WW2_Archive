## 2. 사건 편찬 원칙

1. **시간이 먼저**: 전쟁·작전·학살·군사장비 구상·외교협정·저항운동을 종류에 관계없이 발생일/계획 확정일 순서로 기록한다. 전역처럼 기간이 긴 사건은 **개시일**을 색인 기준으로 삼고, 상세 항목에 종료일을 둔다.
2. **표시 날짜는 확정도가 다름**: `YYYY`, `YYYY-MM`, `YYYY-MM-DD`를 구분한다. 별도 표시가 없는 한 현지 날짜로 기록하며, 국제 날짜변경선 및 시간대 문제를 주석으로 남긴다.
3. **개별 항목 불변 ID**: 사건을 개명하거나 날짜를 정정해도 EVT ID는 유지한다. ID는 시간순 정렬에 쓰지 않는다.
4. **실제 사건과 기획안을 구분**: 예컨대 벚꽃작전의 1945-09-22와 올림픽 작전의 1945-11-01은 *계획상의 목표 날짜*이지 실행일이 아니다.
5. **주제별 기록은 사건 목록에서 파생**: 부대·인물·장비는 별도 개체 파일을 갖고, 사건 및 활동 날짜와 링크한다. 인물의 성향은 후대의 과장된 평가를 피하고 인용 문헌과 반론을 함께 기재한다.
6. **수치는 기준을 함께 기록**: 'XX 사단'과 'YY 명'은 해당 시점과 명목 편제/실전 병력/전투병력/비전투인력 등의 구분을 저장한다.
7. **출처 관리**: 자료명, 기관/저자, 작성·출판 시기, 1차/2차, 문서번호·쪽수(알려진 경우), URL, 접근일, 한계, 라이선스 항목을 보관한다.
8. **논란은 삭제하지 않음**: 양립하는 서로 다른 주장과 수치의 집계 방식을 병기한다.
9. **기록 없는 상상은 배제**: 유력하게 보이는 군사전략·인물 성향·실험 결과라도 1차나 신뢰할 만한 2차 자료 없이는 사실로 쓰지 않는다.

## 3. 상세 항목의 예정 메타데이터

```yaml
id: EVT-0000
title: "항목명"
start_date: "YYYY-MM-DD"
end_date: null
date_precision: day
event_type: operation
event_status: occurred # occurred | planned_only | cancelled
evidence_status: candidate # candidate | source_checked | cross_checked
theaters: []
participants: []
commanders: []
related_entities: []
source_ids: []
updated_at: "YYYY-MM-DD"
```

장비·인물 문서에는 별도 ID(`EQP-`, `PER-` 등)를 부여한다. 사진은 단순 검색으로 가져오지 않고 저작권·초상화 출처·이용 허락을 검토한다.

## 4. 사용자가 제시한 중요 사례의 편집 메모

- **북사할린/남사할린**: 남사할린은 1905년 일본에 양도되고, 북사할린은 1920~1925년 점령되었다. 서로 혼합하지 않는다. 근거 `SRC-001`.
- **터키해협**: 1923년 로잔 협약에 따른 비무장화와 1936년 몽트뢰 협약 이후 터키 재무장 허용을 구별한다. `SRC-014`.
- **글라이비츠 위장공격**: `PS-2751` 선서진술은 중요 1차 사료지만 세부 진행은 지역 박물관 등과 대조한다. `SRC-011` · `SRC-012`.
- **라코니아 인명구조**: 최초 구조의 주체는 독일 잠수함 `U-156`의 함장 베르너 하르텐슈타인 등의 선원이다. 되니츠 개인의 직접 구조활동으로 기술하지 않는다. 이어진 되니츠의 '라코니아 명령'은 별도 연표 항목이다. `SRC-013`.
- **체첸 '학살'**: 먼저 기록상 확실한 1944년 체첸·잉구시인 집단 강제이주(`Operation Lentil`)를 수록하고, 개별 학살 혐의나 규모는 별도 사료로 확인한다. `SRC-016` · `SRC-025`.
- **P.1000 라테**: 해상순양함이 아니라 **육상순양함(Landkreuzer) 구상**이다. 설계 도면의 원본 대조와 실존 사양의 검증이 필요한 미제작 계획. `SRC-018`.
- **검은 관현악단(Black Orchestra)**: 독일 내부 반나치 저항 인맥을 포괄적으로 부르는 이름으로, 단일 조직의 정식 설립일·지휘명령 체계가 있었던 것처럼 다루지 않는다. 관련 개별 인물·음모·쿠데타 사건을 확인하고 연결한다.
- **'보어텍'**: 현재 표기만으로 어떤 역사 사건을 가리키는지 확인하지 못했다. 억지로 연도·내용을 배정하지 않고 이름 검증 대기 항목으로 유지한다.
- **1945년 일본의 벚꽃작전**: 실행되지 않은 생물무기 공격계획이다. 출처에 제시된 9월 22일은 예정일이라는 설명 없이 사건 날짜처럼 표시하지 않는다. `SRC-015`.

## 5. 다음 확대 조사에서 누락되기 쉬운 영역

- **동아시아**: 중국 지방별 전선, 점령지 학살, 731부대 생물전 범죄, 한반도 식민지 동원·강제노동·저항, 만주·남북사할린·쿠릴열도.
- **동부유럽**: 폴란드 지하국가, 발트 3국의 점령과 추방, 우크라이나·벨라루스 점령범죄, 소련의 민족별 강제이주.
- **중동·아프리카**: 이라크, 시리아·레바논, 이란, 동아프리카 전역, 마다가스카르, 프랑스 식민지 병력과 군수.
- **해전·해난**: 호송선단, 북극해, 인도양, 잠수함 사냥, 부상자 구조, 병원선·민간선 피해.
- **정보전·저항**: 암호해독, 기만작전, 요인 구출, 파르티잔·수용소·게토 봉기, 정치적 암살과 실패한 계획.
- **병참·경제·기술**: 군수 생산시설, 레이더·로켓·핵기술 개발 결정, 교통·식량·노동 동원, 개발만 하고 취소한 장비.
- **전범·전후**: 이송·은폐·재판·실종자·송환, 지역별 종전일과 분할 점령의 역사.

이 단계의 목록 340개는 **연구 범위의 첫 골격**이며, 세부 전투 1회·독립 행정명령·특정 함정 사고 등 모든 개별 사실을 담은 결과물이 **절대 아니다**. 추후 각 영역을 나누어 추가 조사 후 중복·출처를 다시 점검한다.

## 6. 자동화된 자료 정합성 검사

- `python research/validate_index.py`로 고유 이벤트 ID, 출처 ID 참조, 날짜 형식, 연표 정렬, Markdown 테이블 열 수 및 출처 상태 일관성을 점검한다.
- `.github/workflows/research-index-check.yml`에 의해 Pull Request 변경 시 동일한 검사가 실행된다. **이 검사는 역사적 사실의 참·거짓을 검증하지 않는다.**
- 등록 출처 ID는 **128개**이며 기존 별칭 `SRC-028`(=`SRC-004`)과 `SRC-056`(=`SRC-003`)의 **중복 URL 두 건**을 별도 표시했다. 따라서 출처 91개를 서로 독립적인 사료 91종이라고 부르면 안 된다. 문헌별 서지사항도 단계적으로 감사 중이다.
