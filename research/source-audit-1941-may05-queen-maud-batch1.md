# 1941-05-05 대서양: Queen Maud / U-38 — 부분 검증

**신규 EVT 0 / SRC 1 / RQ 1.** 전 세계 5월 4~9일 전수조사 미완료. 기존 chronology-1939-1941.md에서 Queen Maud·U-38·OB-309 문자열 중복 확인 결과 해당 사건이 등록되지 않았다. 아직 독립 1차 사료가 없어 EVT는 보류한다.

## 직접 확인한 2차 자료
- **SRC-1900 후보**: uboat.net, *Ships hit by U-boats: Queen Maud*, https://uboat.net/allies/merchants/900.html (열람 2026-11-05). 온라인 선박 피해 데이터베이스(2차 편찬, 저자·개별 게시일 웹 표시 미확인, 인쇄 쪽수 없음). 영국 상선 Queen Maud(4,976 GRT), 1941-05-05, U-38(Heinrich Liebe)에 의해 프리타운 서쪽에서 격침되었다는 편찬 기록. 분산된 OB-309 소속, 승선자 44명 중 1명 사망·43명 생존, 포르투갈 Mirandella 구조 및 HMS Dragon 인계라는 **데이터베이스 주장**이다. 공격 시각 11:05·11:17, 위치 7°54′N 16°41′W, 적재량 7,320톤도 이 자료의 주장으로만 보관.
- 원 잠수함 KTB, 영국 Admiralty 상선 손실 카드·Lloyd's War Losses, Mirandella/HMS Dragon 항해일지, 생존자·전몰자 원명부는 **열람하지 않았다**. 당시 독일/영국 시각 기준과 선박의 위치·구조일 독립 확인 필요.
- 권리: 해당 사이트의 사진·텍스트를 복제하지 않고 URL과 자체 요약만 등록한다. 자료 재사용 라이선스는 확인하지 못함.

## 미해결
**RQ-1124**: 원 KTB·Admiralty/선박 기록을 찾아 공격일·시각·좌표, 피해 선원, 선단 이탈 및 포르투갈 중립선 구조, HMS Dragon 인계·5월8일 상륙을 독립 대조한다. 선박 4,976 GRT와 화물 7,320톤은 서로 다른 지표이며 혼동하지 않는다. 사료 교차 전 신규 EVT 등록 보류.
